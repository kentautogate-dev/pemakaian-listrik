    Nyalakan helper otomatis

    Tombol otomatis butuh pemasangan sekali: jalankan pasang-otomatis.cmd. Setelah itu helper juga menyala sendiri setiap Windows login. Windows bisa menampilkan konfirmasi “Open Backup Listrik?” — pilih Buka / Open.

    Helper sudah dijalankan tapi masih belum aktif?
    1. Tunggu 2–3 detik lalu tekan Coba lagi (halaman ini juga mencoba otomatis setiap 3 detik).
    2. Pastikan jendela hitam Helper Backup Listrik masih terbuka. Kalau tertutup, jalankan mulai-backup.cmd lagi.
    3. Kalau ada pesan port 8787 dipakai: jalankan hentikan-backup.cmd, lalu mulai-backup.cmd lagi.
    4. Kalau jendela hitam langsung tertutup: cek Node.js di Command Prompt dengan node -v. Bila error, pasang Node.js dari nodejs.org.
    5. Uji manual: buka http://127.0.0.1:8787/api/status di tab browser. Bila muncul {"ok":true,...} berarti helper sehat.
