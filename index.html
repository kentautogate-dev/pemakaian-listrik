Konfigurasi SolaxCloud buka/tutup
Akun SolaxCloud biasa (end-user) tidak punya menu Service → API. Pilih Developer Portal: buat aplikasi sekali di developer.solaxcloud.com untuk mendapat Client ID/Secret.
Diambil dari akun SolaxCloud: Service → API. Disimpan lokal di komputer ini.
Umumnya https://www.solaxcloud.com. Bisa diganti sesuai region akun.
App Code (UUID) bukan Client ID. Buka aplikasi di Developer Portal → bagian Authorization Key untuk melihat Client ID & Client Secret.
Cara mendapatkan akses (TokenId atau Developer Portal)
  1. TokenId (akun installer/distributor): login SolaxCloud → menu Service → API → salin TokenId. WiFi SN = nomor seri dongle/Registration Number inverter.
  2. Developer Portal (akun SolaxCloud biasa/end-user): buka developer.solaxcloud.com → login dengan akun SolaxCloud → Applications → Create App → isi nama/aplikasi → pilih akses API (plant/device data) → simpan.
  3. Setelah aplikasi dibuat, salin Client ID dan Client Secret, lalu masukkan di mode Developer Portal di atas. Bila muncul kode 10403, tambahkan/otorisasi Service Package API di Developer Portal.
  4. Kalau kedua jalur belum tersedia: gunakan penanda manual “PLTS off-grid” di catatan harian; SOC tetap bisa dipantau dari aplikasi SolaxCloud.

Cara menandai hari PLTS off-grid (tanpa API)
  1. Saat mencatat sisa kWh pagi, centang “PLTS off-grid (baterai habis) hari ini” bila sejak catatan sebelumnya baterai habis dan listrik memakai PLN.
  2. Kalau baru sadar besok paginya (baterai habis semalam): buka tab Catatan Listrik → tombol ✎ pada catatan kemarin → centang → Simpan perubahan.
  3. Bisa juga dari halaman ini: tombol “Tandai kemarin (tanggal) PLTS off-grid”.
  4. Untuk menghapus tanda: tombol Hapus tanda, atau buka catatan lalu hilangkan centangnya.
  5. Halaman ini dan analisa bulanan akan membandingkan rata-rata kWh/hari saat off-grid vs hari normal.

Nyalakan helper otomatis

Tombol otomatis butuh pemasangan sekali: jalankan pasang-otomatis.cmd. Setelah itu helper juga menyala sendiri setiap Windows login. Windows bisa menampilkan konfirmasi “Open Backup Listrik?” — pilih Buka / Open.

Helper sudah dijalankan tapi masih belum aktif?
  1. Tunggu 2–3 detik lalu tekan Coba lagi (halaman ini juga mencoba otomatis setiap 3 detik).
  2. Pastikan jendela hitam Helper Backup Listrik masih terbuka. Kalau tertutup, jalankan mulai-backup.cmd lagi.
  3. Kalau ada pesan port 8787 dipakai: jalankan hentikan-backup.cmd, lalu mulai-backup.cmd lagi.
  4. Kalau jendela hitam langsung tertutup: cek Node.js di Command Prompt dengan node -v. Bila error, pasang Node.js dari nodejs.org.
  5. Uji manual: buka http://127.0.0.1:8787/api/status di tab browser. Bila muncul {"ok":true,...} berarti helper sehat.
